# 3D modeller

Aşağıdaki `.stl` dosyalarına GitHub'da tıklayınca model tarayıcıda **3D olarak açılır**. Fareyle döndürebilir, tekerlekle yakınlaştırabilirsiniz.

| Model | GitHub'da 3D önizleme | Oyunda kullanılan dosya | Kaynak |
|---|---|---|---|
| SLS roketi | [sls.stl](sls.stl) | [`public/assets/sls.glb`](../public/assets/sls.glb) | [NASA 3D Resources — SLS](https://science.nasa.gov/3d-resources/space-launch-system-sls/) |
| Orion kapsülü | [orion.stl](orion.stl) | [`public/assets/orion.glb`](../public/assets/orion.glb) | [NASA 3D Resources — Orion](https://science.nasa.gov/3d-resources/orion-capsule/) |
| Astronot | [astronaut.stl](astronaut.stl) | [`public/assets/astronaut.glb`](../public/assets/astronaut.glb) | [NASA 3D Resources — Astronaut](https://science.nasa.gov/3d-resources/astronaut/) |

- `orion.stl` NASA'nın orijinal dosyası.
- `sls.stl` ve `astronaut.stl`, oyundaki GLB dosyalarından Blender ile dışa aktarıldı. SLS oyun için sadeleştirildi. Orijinal STL 78 MB olduğu için repoya eklenmedi, yukarıdaki NASA sayfasından indirilebilir.
- STL dosyalarında renk ve malzeme bulunmaz. Renkli hâlini görmek için GLB dosyasını indirip [gltf-viewer.donmccurdy.com](https://gltf-viewer.donmccurdy.com/) sayfasına sürükleyin ya da Blender'da **File → Import → glTF 2.0** ile açın.
- NASA görselleri ve modelleri [NASA medya kullanım kurallarına](https://www.nasa.gov/nasa-brand-center/images-and-media/) göre kullanılır.
